# D'REGAL

A static fashion storefront built with HTML, CSS and vanilla JavaScript. Open `index.html` with VS Code Live Server to preview it locally.

## Editing the site

- `js/products.js` is the single source for product names, prices, colours and images.
- `css/style.css` contains the visual system and reusable components; `css/responsive.css` handles small screens.
- `js/cart.js` saves the bag in local storage and creates the WhatsApp order message.
- Each page is a standalone HTML file, with shared header and footer markup added by `js/main.js`.

Temporary campaign images load from Unsplash and are labelled in the interface. Replace their URLs or add local images inside `assets/images/` when D'REGAL photography is ready.
