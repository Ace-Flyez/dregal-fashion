# D’REGAL mobile navigation update

The mobile navigation has been updated to the approved drawer direction.

## Included
- D’REGAL wordmark and `BEYOND THE ORDINARY` subtitle.
- Home, Shop, Our story, Contact and FAQ links with a consistent inline outline icon set.
- High-contrast active-page treatment.
- Separate Wishlist and Shopping bag shortcuts with live counts.
- Brand-story panel: “Contemporary fashion. Room to be yourself.”
- Appearance control with Light, Dark and System preferences.
- Dark-theme styling, reduced-motion handling, close button, outside-click dismissal and Escape-key dismissal.

## Run locally
Open the extracted project in VS Code and use Live Server, or open `index.html` in a browser. The site uses remote Google Fonts and Unsplash images, so an internet connection is needed for those assets.

## Verification
The JavaScript syntax check, project lint command, typecheck script and four existing compliance tests pass. A real browser/device interaction test was not available in this run, so please check the drawer at phone width before deployment.
